# Asset licences

Every file under `assets/` has an entry here: where it came from, who made
it and under what licence. A file with no entry does not belong here.

**Rule for third-party assets.** Only assets that are clearly **CC0**
(public domain dedication) are accepted, and only with the source URL,
the author and the date it was fetched recorded below. No CC-BY, no
"free for personal use", no store licence: a credit or a restriction would
travel into every reel. Converted assets are re-exported as OBJ in metres,
+z up (Blender's frame), with the house material names
(`tools/blender/README.md`).
